Guia de bolso

Comandos Essenciais

git init

Usado para iniciar o projeto git

git add .

prepara as informações locais,envia elas para a staging area

git commit -m "[mensagem pra lembrar do que fiz antes de salvar]"

salva ne

git push -u origin main

esse moscão aqui empurra as informações para o site

git fetch

Verifica se o repositório remoto tem modificações em relação ao local

git pull

puxa as informações externas para o pc

git clone[link do repositório]

puxa todo o repositório e cria uma branch

git remote add origin[link do repositório]

é usado para vincular um repositório local a um repositório remoto.

utilize os comandos pisando fofo pae
